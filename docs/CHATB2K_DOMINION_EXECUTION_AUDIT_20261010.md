   - `auth_leaked_password_protection`: 1 warning (compromised-password protection not enabled).

The first production workflow run after merge is still in progress; a real BIGO media archive and downstream fetch remain unproven. Keep Blob operational until the PR is reviewed, a large-file upload is verified against Dropbox read-back, the asset registry is updated, and downstream media fetch succeeds.
